# 本日のPICK-UP カレンダーの使い方

店舗スタッフ向けです。パソコンでもスマホでも使えます。

1. 店長からもらった**リンク**を開きます。  
   LINEの中で開いたときは、右上の「…」から **Safari**（iPhone）または **Chrome**（Android）で開き直してください。LINEの画面のままでは、動画が保存できないことがあります。
2. 店舗名と、今月・今日の日付を確認します。
3. 本日のキャストの**名前**と**写真**を入れます。
4. これまでの日の写真を入れます。「写真をまとめて選ぶ」で一度に入れられます（選んだ順に1日から入ります）。マスを指でずらすと、顔の位置を直せます。
5. 「プレビュー再生」で動きを確認します。
6. 「動画を保存」を押し、保存した動画を Instagram のストーリーズに投稿します。  
   いちばん最後の絵だけ欲しいときは「PNG保存」です。

写真と名前は、その端末の中に自動で残ります。機種を変える前に「バックアップを保存」を押してください。

**うまく保存できないとき**
- iPhone なら Safari、Android なら Chrome の最新版で開き直す
- 画面に「WebM」と出たら、Instagram 用には iPhone の Safari で保存し直す（MP4 になります）
